Shared Blueprints for Spaceflight Simulator PC Steam (Windows)

1. Save your game progress and close Spaceflight Simulator.
2. Double-click Install.cmd. It will find a standard Steam install or ask for the game folder.
3. If asked, select the folder containing Spaceflight Simulator.exe.
4. Open the build scene. Click Workspace to the left of New, or press F8.
5. Sign in with the username and password used on the workspace website, or
   create a new account using the workspace invite code.
6. Use the Workspaces tab to switch libraries or join another one with its code.

Server URL: https://hanson07101.top/blueprints
Member website: https://hanson07101.top/blueprints/

Existing blueprints are never overwritten. Install.ps1 makes backups when replacing
an older mod DLL or changing ModsSettings.txt. It checks the DLL against
manifest.json before changing files. For a read-only install check, run:
  powershell -File Install.ps1 -CheckOnly

The workspace opens as a modal panel. Drag its title to move it, and close it
before editing the rocket.

This package has been built and archive-checked on macOS; Windows game loading
and in-game interaction still require testing on a real Windows machine.
