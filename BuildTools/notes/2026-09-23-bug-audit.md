# BuildTools 定向 Bug 检查（2026-09-23）

目标环境为 Mac Steam 游戏 `1.6.00.16`、Unity `6000.1.17f1`。本检查依据当前源码、游戏程序集反编译结果、`Player.log` 和用户实际操作反馈。游戏内功能结论需在安装本轮 DLL 后重新验收；Windows 状态不能由 Mac 推断。

| 路径 | 当前证据与结论 | 本轮处理或待验收 |
| --- | --- | --- |
| Part 页坐标与数值 | BT-005 已由用户实测：拖动后 X/Y 更新，点加减不跳回；朝向、数值变量由同一刷新机制处理 | 正常编辑时继续留意手工输入的半成品文本及其他数值 |
| Build 页原生 Q/E 旋转 | 游戏 `BuildMenus.Start` 直接把 Q/E 绑定到 `Rotate(±90)`；`CustomRotation` Harmony 补丁在 Mac 日志中被跳过，用户确认旧版设置 1° 后仍转 90° | BT-006 替代绑定已加载，用户确认 Q/E 均按 1°旋转；倒置开关及 JSON 输入焦点仍待验收 |
| Ctrl+Q/E 自定义旋转 | 原设计在 `Invert Rotate Keybinds` 关闭时使用 90°，开启时使用设置值；这与原生 Q/E 的自定义/标准步长互换 | 保持设计；验收时按开关两态核对，不把关闭状态下 Ctrl+Q/E 的 90°误判为故障 |
| Build Settings 保存 | Build Settings 使用 `Config.txt`，Part Editor 使用 `config.txt`；在本机不区分大小写的磁盘上是同一路径。Build 页的 Save 原先只改内存值，直到退出才写文件 | 改为独立 `BuildSettings.txt`；原有 Build Settings 1°配置与 Part Editor 配置均保留。用户点击 Save 后已核对文件即时写入 1°；重启后 UI 保留值仍待验收 |
| 数值输入 | 过长输入会回显旧文本，但此前仍可能把原数写入内存；输入 0 会显示 0 而实际恢复默认值；非有限数未排除 | 已调整解析和回显，待手动输入边界值验证 |
| Snap to Parts | `snapping` 只被 Harmony `KillMagnet` 读取；该补丁在 Mac 被跳过，故开关目前没有证据能影响游戏吸附。原补丁参数类型与游戏的 `MagnetModule[]` 也不一致 | 已修正补丁参数，供能正常补丁的平台使用。Mac 吸附功能仍需单独实现或明确停用，未把开关当作已修复 |
| Part Adaptation | `adapting` 只被 `StopAdaptation`、`FixCucumber` 读取；相关补丁均被跳过 | Mac 开关当前无效，需单独方案和实际零件验收 |
| Grid Snap | 自定义值只被 `CustomGridSnap` / `OffsetPartsRoundToGridSnap` 读取；两补丁均被跳过。当前游戏 `DevSettings.DisableNewBuild` 为 true，使用旧吸附路径，但未被本 Mod 改写 | Mac 自定义 Grid Snap 当前无效，需单独方案和碰撞回归验收 |
| Part 页、JSON 页与切页 | 三页外框、JSON 方向键、滚轮和草稿曾由用户验收。`WindowFocus` Harmony 补丁仍被跳过；本 Mod 已直接保护自定义键和 JSON 滚轮，新 Q/E 替代绑定也会在文本焦点时跳过 | 待用测试零件复查 JSON 聚焦时 Q/E、删除/翻转等原生键，切页后草稿和普通建造输入 |
| 非 90° 零件翻转/镜像 | `FixFlippingAndMirroring` Harmony 补丁被跳过；默认设置虽为 true，效果未运行 | 1°旋转后需实机检查翻转/镜像；不在无复现时重写游戏算法 |
| 双击选中与轮廓宽度 | `DisableDoubleClickSelect`、`SetOutlineWidth` 补丁被跳过；前者默认关闭，后者只影响轮廓视觉 | 记录为已知限制，不作为本轮旋转路径的成功条件 |
| 其他 Build 操作 | 移动/缩放快捷键、无限区域和零件重叠开关走直接游戏 API；隐藏皮肤开关也走直接数据路径 | 源码路径可达，仍需在测试蓝图上抽查实际操作与权限限制 |
| 旧独立 Mod | `Mods/PartEditor.disabled-by-buildtools` 仍被加载器扫描并报找不到同名 DLL | 游戏退出后将整个目录移到 `Mods` 外的备份位置，消除该已知启动错误，不删数据 |

本轮已验证 Q/E 旋转与 Save 即时写盘；吸附、适配、网格间距涉及游戏吸附及碰撞算法，暂不以未经实机验证的覆盖逻辑替代。验收结果、未解决项与 Windows 边界继续记录在 `PROJECT_LOG.md`。
